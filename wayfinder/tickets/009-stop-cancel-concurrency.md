## Question

用户控制与并发行为（Q8 已定后台线程 + tool-calling 循环）：

1. **停止按钮**：tool-calling 循环中途点停止——语义是"放弃本轮"还是"放弃当前工具继续回答"？实现上如何中断（HTTP 连接关闭？标志位？）
2. **主动搭话与用户聊天并发**：搭话生成中用户发消息，如何取消/合并？
3. 多个工具串行执行时，用户能否看到中间进度（还是只有最终折叠卡片）？
4. 记忆抽取（异步）与用户聊天的资源竞争（同一 LLM key 的并发调用限制）

依赖票据 1 确认模型能力后决议。

## Resolution

诘问一轮定案（2026-09-05）：

1. **停止语义**：停止 = 放弃整个 agent 循环（中断当前 LLM 请求/工具，丢弃未完成输出，气泡显示"已停止"）
2. **中断实现**：HTTP 连接关闭（非流式请求）+ `threading.Event` 取消标志（每步循环检查）；run_python 用 `Popen` + `terminate`；不杀线程（防 SQLite/UI 损坏）
3. **主动搭话并发**：触发前抑制（聊天窗打开/输入聚焦跳过）；生成中用户发消息 → 放弃搭话，用户消息优先，结果不合并进上下文
4. **工具进度**：状态流转卡片（等待 → 🔧 运行中… → 完成），UI 实时更新不阻塞；回灌 LLM 的仍只有最终结果（票据 008）
5. **LLM 并发**：单 worker 队列，优先级 用户聊天 > 主动搭话 > 记忆抽取；同一时间只发一个请求
