## Question

聊天窗口（Q7 已定 PySide6，Q19 已定工具调用折叠卡片）的视觉方案长什么样？用户明确要求"UI 足够美观"。

需要产出（原型，供用户反应）：

1. 消息气泡方案：用户/搭子配色、圆角、头像（沿用 pet_image 还是新图标）、Markdown 渲染范围（代码块/表格/公式？）
2. 工具调用卡片样式（折叠态与展开态）
3. 侧边栏（换功能/设置/记忆查看入口）与整体明暗主题
4. 搭子主窗口（无边框透明 + gif 动画 + 气泡）与聊天窗的风格统一

用 prototype 技能做 1~2 张可交互的静态原型（QSS 代码或截图级描述），挂到票据下。

## Resolution

原型已产出：`prototypes/ui-visual/prototype.html`（丢弃件，3 变体可切换）。用户选择 **变体 C — 搭子互动式**（2026-09-05）。

定案要点（C 方案）：
- **布局**：伙伴形象大卡片（渐变头像 + 昵称 + 性格 + 气泡）与聊天窗并排；聊天窗为大圆角卡片（24px）浮于暗色渐变背景上
- **气泡**：用户右侧渐变紫蓝（18px 圆角、6px 小尖角），搭子左侧深色圆角；头像用伙伴图标
- **工具卡**：便签风（暖黄色圆角卡片，"run_python 完成啦"，可展开看输出）
- **记忆感知**：聊天窗头部显示记忆 chips（"记得你：偏好向量数据库"、"🧠 3 条记忆"）
- **主题**：暗色底 + 紫/粉/橙渐变强调；`ui.theme=dark` 默认

实现时以 PySide6 QSS 落地该视觉：渐变气泡需自定义绘制（QPainter 圆角+尖角），其余可用 QSS 完成。原型保留在 `prototypes/ui-visual/` 供参照。
